Where it stands

Every step built, in the order each needs the one before.

A cloud and a timed machine are each built in the order their parts depend on one another. This page says what each step does and what judges it: every one boots on an emulated machine and is held, line for line, to what it said before.

The cloud

From one server to a lost machine.

1 · A serverA solution's server, placed on a machine. A pack, the server programs written apart from any machine, is put on one, which runs the server as a confined program under a user of its own. Judged by a boot compared line for line with its kept transcript, and by the same machine with no disk behind the server's directory, which does not start it.built · emulated
2 · Two linksA box that is the way between two networks. The fleet file says which box and which networks, and a till on one network reaches a server on the other through it. Judged by three machines on two networks, by the same box without its one line, and by a device nobody declared, which is given nothing.built · emulated
3a · TimeA date a record can lean on. A fleet's one time authority signs that an entry of a record existed no later than a time it read from its clock; a record with no such statement says it is ordered and undated. Judged by two machines on one wire, and by breaking each rule to see that a check catches it.built · emulated
3b · A frontA program at the edge that ends TLS, with its key on a disk the machine declares. Built on one machine: the proxy runs as an identity of its own, binds 443 and no other port, ends TLS under a root it was given by hand, and reaches the server behind it in plain HTTP on the machine's own loopback; a question for the wrong name is refused, and a plain question on the TLS port gets a 400. And on the box between two links: the cloud's file names which machine is the door of a network and under which root, by its fingerprint; the till asks the door by its name, trusting only the root it was given, and the fingerprint it prints is the one the file declares. The box with forwarding taken out still answers at the door: a front is a way of its own, which is why the file declares it.built · emulated
3c · A copyOne machine keeps a verified copy of another machine's program directory. The file names which machine gives the files of a program's own directory and which one keeps them. The keeper asks over the link, checks the list the giver signed, writes the files into a place of its own, reads them back, and keeps the last complete copy or none. The giver follows no link and gives only files its program owns. Judged by two machines on one wire and the negatives read off their disks: another machine answering at the giver's address, a device the giver does not give to, a link in the directory, a file that is the machine's own key under another name, a copy changed on its disk, and a machine whose disk the kernel refused.built · emulated
3d · A roll callWho has written a record since. One command reads every member's record, brought to it with the statements beside it, against the cloud file's keys and its time authority's word, and against the roll before it: whose each record is, how far it goes, who wrote, who has nothing new, whose record went backwards, and what a machine nobody could bring last held. A record that goes backwards stays flagged until a person accepts it, and a copy older than the roll says is caught when the authority's date contradicts it. Judged on the time step's real arc, rolled over in eighteen sections.built · emulated
3e · A loss drillOne machine destroyed while the cloud runs. Two machines run, one giving a program's directory and the other keeping a checked copy. The first is switched off at once and its disk erased; the second goes on asking, finds nobody, and keeps its copy, which anyone holding the cloud file can check; the roll call names the lost machine as absent, with what it last held of it, and a machine rebuilt on the same file is a new device until it is enrolled.built · emulated

The timed machine

From the kernel to the safe state.

1 · A timed kernelA kernel that can meet a deadline, built to be interrupted almost anywhere, with timers that resolve to the nanosecond, derived from the fact that a program reserves time. Judged by the machine reading back, at every boot, what kernel it got.built · emulated
2 · A reservationTime the kernel holds for a program: a period, a deadline, a runtime and a core, on a core set apart, handed to the program before its first instruction. Judged by a boot of two reserved programs and one with none, by the court's cases, and by four things put wrong on purpose, each refused on the line that names it.built · emulated
3 · A measurementHow late the program actually woke. A witness runs the declared period on an absolute timer and says the median, the 99th, the worst and the misses. The kept transcript holds the line's shape and no number, because an emulator's time is its laptop's.built · emulated
4 · A safe stateA program is told when it runs past its time. A program that runs past its reserved time is told so by the kernel once it asks to hear it, and is ended by the word if it does not handle it; the court refuses a health window shorter than the machine's own look; and the machine checks at every boot that its kernel can send the word. Judged by the measuring machine's neighbour, which waits for the word before it says it is ready, and by four things put wrong on purpose.built · emulated

How a step is judged

By what the machine said, read back.

  • Every boot is held to its kept transcript. A step is built when its machines boot on an emulated PC, say what they did, and match, line for line, what they said before; the latency a program measures there is the emulator's, and the transcript keeps its shape and no number.
  • A real server stands in the cloud. RingServ, the estate's application server, is placed by a pack on a machine of its own and reached through the box that joins two networks.
  • Time has one source, and every statement is checked. One authority per fleet signs that an entry existed no later than a time it read from its own clock, and anyone holding the fleet file checks it.
  • A floor for real-time systems. A real-time system is built on it: a program is given its time and keeps its own loop, one core per program, and what it starts runs unreserved.
  • No kernel's word is taken on trust. Five numbers copied from the kernel's source were wrong when the kernel was asked, and each was caught by a line the machine prints to be read back.
  • A loss is said with numbers. When a machine of the cloud is destroyed, the rest keep its copy and the roll call says what it last held.
