The words

Eight terms, before they start doing work.

This page and the next few use a small vocabulary, and it is worth ten seconds now rather than a guess later. The machine defines these itself — harb learn --words prints the list and a few more.

a machineOne computer, written down: what it is, what it mounts, what it runs. One .machine file, and nothing more — it is text until something builds it.
a declarationA block in that file. Its RATIONALE is not a comment: the grammar requires it, so every part of a machine has to say why it is there.
a worldOne running program the machine declared, once it is alive. Called a world because it gets its own little universe — its own view of the network, the storage and the process table.
the envelopeWhat the kernel lets a world see and do. Derived from what that world declared it needs, never granted by a separate permission file someone can edit later.
the courtThe judge of the grammar. Cases that must be accepted, and more that must be refused — each carrying the exact words its refusal has to contain.
a pinA stored copy of everything a boot should print. Boot again and the two are compared, so a change shows up as a difference instead of a shrug.
the transcriptEverything one boot actually printed, from the first line the machine speaks to the halt. The pin is what it should have said; the transcript is what it did.
a fleetA set of machines judged together. Some mistakes are only visible across a set: two boxes that each call themselves the server of one network are each faultless alone.

Named for the Harobanda bridge across the Niger River that joins the two banks of Niamey, the capital. The OS also joins a solution's promises to the machine that keeps them.
